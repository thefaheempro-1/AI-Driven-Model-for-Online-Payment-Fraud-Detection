# AI-Driven-Model-for-Online-Payment-Fraud-Detection
Machine learning framework for detecting fraudulent online payment transactions, handling class imbalance and comparing multiple classifiers. M.S. IT thesis, The Islamia University of Bahawalpur.
This repository contains the source code for my M.S. thesis, “AI-Driven Model for Online Payment Fraud Detection”, completed at The Islamia University of Bahawalpur under the supervision of Dr. Musarat Karim. The project builds and evaluates machine learning models that identify fraudulent online payment transactions, addressing challenges such as highly imbalanced data and the need for high recall without excessive false positives.
